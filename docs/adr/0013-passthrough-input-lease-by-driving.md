# Input is passthrough-by-default; the Leader is the only reserved key; the Focus Lease follows resize, never keystrokes

The original input model was modal: dashboard keys drove the UI, and only entering Focus switched to passthrough. The #11 design review reversed it: in Tiles and Focus, every unmodified keystroke forwards byte-faithfully to the selected/focused Pane's Agent, and every dashboard verb lives behind the single configurable Leader (default `Ctrl-\`) — the tmux/Hyprland contract, "everything is the Agent's except the Leader". Two consequences are deliberate: Enter is an Agent key (answering an Agent's prompt requires it), so Focus is entered by a Leader verb, never Enter; and Agents sit at `proceed? [y/n]` prompts, so we accept the stray-keystroke hazard in exchange for zero-ceremony triage — which is also why tile order must never change except by the developer's own verbs.

The Focus Lease follows the same principle, narrowed to geometry: it is taken by *resizing*, not by looking or typing. A Client's `ResizeRequest` on a Pane (in practice Focus entry — only Focus resizes, ADR-0014) steals the lease implicitly, server-side; there is no `AcquireFocus` message, and keystrokes neither block on it nor transfer it — input is always delivered, and an input-only steal was rejected because a Tiles keystroke would strand another Client's Focus geometry: the robbed Client's unfocus restore would be ignored, while the thief, having no Focus lifecycle, never sends one, pinning the Pane at focus dimensions until the thief disconnects. Selection and browsing put nothing on the wire — so `FocusChanged` telemetry names who holds a Pane's geometry instead of churning with navigation or typing. Stealing composes with the Server-owned restore record: the pre-drive size travels with the lease instead of being re-recorded per stream, so a mid-Focus steal can neither orphan the Pane's original size (the thief's restore returns to the true pre-drive size, not the victim's focus size) nor let the robbed stream yank the Pane from under the new holder (`RestoreSize` and the implicit restore-on-death are honored only from the holder). Rejected: an armed-input toggle (reintroduces mode-tracking the reversal exists to remove), Status-gated forwarding (the same key changes meaning on an async Status flip — a nondeterministic stray-`y`), lease-on-selection (browsing from a second Client would silently yank leases), and lease-on-keystroke (the stranding above).
